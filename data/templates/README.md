# Gabarits à imprimer, par langue

Un dossier par langue : `fr` (français), `en` (anglais), `es` (espagnol),
`de` (allemand). Le site prend les gabarits du dossier de la langue choisie
avec l'écusson ; s'il manque un fichier, il reprend celui du dossier `fr`.

Fichiers attendus dans chaque dossier (mêmes noms partout) :

- `couverture.jpg` : page de garde (nom et type de la bande)
- `bande.jpg` : fiche de bande (nom, type, biographie, valeur de bande)
- `compte.jpg` : compte de bande (couronnes, pierres magiques, réserve)
- `effectif.jpg` : liste de l'effectif (13 lignes avec profils)
- `hero.jpg` : fiche de héros (une par héros)
- `homme_de_main.jpg` : hommes de main (5 groupes par page)
- `regles.jpg` : page de règles (répétée autant que nécessaire)
- `historique.jpg` : historique des combats (répétée autant que nécessaire)

Format : 1414 × 2000 pixels, PNG ou JPG.

Le texte est écrit aux emplacements définis dans `tools/coords/*.json`
(communs à toutes les langues pour l'instant).
