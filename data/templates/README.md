# Gabarits à imprimer, par langue

Un dossier par langue : `fr` (français), `en` (anglais), `es` (espagnol),
`de` (allemand). Le site prend les gabarits du dossier de la langue choisie
avec l'écusson ; s'il manque un fichier, il reprend celui du dossier `fr`.

Fichiers attendus dans chaque dossier (mêmes noms partout) :

- `bande.png` : fiche de bande
- `hero.png` : fiche de héros
- `homme_de_main.png` : fiche d'hommes de main
- `regles-vierge.png` : page de règles (fond seul, répété autant que nécessaire)

Le texte est écrit aux emplacements définis dans `tools/coords/*.json`
(communs à toutes les langues pour l'instant).
